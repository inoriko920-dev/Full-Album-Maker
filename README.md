# Full Album Maker

Repository pemulihan sementara setelah akun GitHub lama tidak dapat diakses.

## Sumber pemulihan

Arsip portable yang berhasil diselamatkan: `Full-Album-Maker-Windows-Portable.zip`.

Isi utama arsip tersebut adalah build Windows portable, bukan source repository lengkap. Build berisi `Full Album Maker.exe`, dependensi PySide6/Python, FFmpeg/FFprobe, aset, lisensi, dan metadata aplikasi.
